## About

I build security systems end to end: the architecture, the telemetry, the detection logic, the automation, the testing and the documentation. I like working the full attack lifecycle, from reproducing a CVE and building a PoC to investigating the logs, PCAPs and endpoint evidence it leaves behind.

```yaml
focus:       Incident Response, Detection Engineering, Malware & Threat Research, Cloud Security
cloud:       GCP, AWS
deepening:   DFIR, Active Directory, cloud incident response, reverse engineering, patch diffing
open_to:     Full-time security roles (IR, detection, threat research, cloud security), India or remote
note:        Much of my work lives in private repositories. Happy to walk through it.
```
